# Appendix C: Worksheets {.unnumbered}

Each worksheet can be rebuilt in a spreadsheet in a few minutes, or copied onto paper. Formulas are written in words so they work in any tool. If you want a spreadsheet version, paste a worksheet into your AI assistant and ask: *Turn this into a Google Sheets layout with column headers and the formulas written out for row 2.*

## 1. Sellable minutes

For each barber, for one week:

| Line | What to enter |
|---|---|
| A | Minutes in the shop each day, added up for the week |
| B | Lunch minutes per day × days worked |
| C | Cleaning, restocking and admin minutes per day × days worked |
| D | Any other blocked time (meetings, training, personal) |
| Sellable minutes | A − B − C − D |

Cedar Street, Dre: A = 2,700, B = 150, C = 150, D = 0. Sellable = 2,400.

## 2. The weekly scorecard

Fill in on the same day each week. Keep the count next to every rate.

| Measure | How to calculate | This week | Last week | Baseline |
|---|---|---|---|---|
| Utilization, per barber | Completed service minutes ÷ sellable minutes | | | |
| Missed-contact recovery | Calls and messages answered or returned ÷ total missed | | | |
| No-show rate | No-shows ÷ appointments due (exclude cancellations made in time) | | | |
| Late-cancel rate | Late cancellations ÷ appointments due | | | |
| Checkout rebooking | Eligible visits leaving with a future booking ÷ eligible completed visits | | | |
| First visits completed | Count, with source (Google, Instagram, referral, partner, ad, walk-by, other, unknown) | | | |
| Note | What we changed; anything unusual this week | | | |

Optional monthly lines: new reviews and review requests (counted separately), first-visit return rate, retail attach rate, contribution per occupied chair hour.

**Contribution per occupied chair hour** = (service revenue after discounts − direct variable service costs) ÷ completed service minutes × 60.

## 6. Offer break-even calculator

| Line | Item | Value |
|---|---|---|
| 1 | Normal price | |
| 2 | Direct costs per visit | |

| 4 | Discount or reward per visit | |

| 6 | Usual completed visits in this window | |
| 7 | Visits needed to break even (6 × 3 ÷ 5) | |
| 8 | Extra visits needed (7 − 6) | |

Cedar Street example, $5 off a $35 cut, 7 usual visits: line 3 = $30, line 5 = $25, line 7 = 7 × 30 ÷ 25 = 8.4, so 9 visits; line 8 = 2 extra visits needed.
